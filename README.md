# 🎃 Reunión Día de Disfraces - Cinemática de Terror

¡Bienvenid@ al repositorio del evento especial de disfraces! Esta es una aplicación web interactiva diseñada para organizar la reunión familiar del 24 de Octubre de 2026.

## 🚀 Características
- 🏠 **Panel de Inicio:** Información general sobre el evento (fecha, temática y detalles).
- 📋 **Menú Interactivo:** Los invitados y familias pueden seleccionar y apartar qué plato llevarán para compartir.
- 🦇 **Directorio de Familias:** Lista de las familias convocadas al evento.
- ⚰️ **Cinemática del Ataúd & Screamer:** Experiencia interactiva de terror con efectos de sonido e imagen integrada.

## 🛠️ Tecnologías utilizadas
- **HTML5** para la estructura.
- **CSS3** para los estilos oscuros, animaciones y modales.
- **JavaScript (Vanilla)** para la lógica de selección, almacenamiento local (`localStorage`) y efectos de audio.
